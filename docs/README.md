## Working on Ship

The [codebase map](agents/codebase.md) explains the crates and build prerequisites. Read the [code guidelines](agents/code.md) before changing Rust and the [docs guidelines](agents/docs.md) before changing the guide.

The [product brief](product-brief.md) explains the direction and what remains outside the current scope. [Research notes](research/README.md) preserve experiments and comparisons, not instructions for using today's Ship. [Blog posts](blog/) describe the project at the time they were written.

For exact behavior, see [OpenSpec requirements](../openspec/specs/). Only locked design papers with Cyan's recorded approval authorize implementation; the brief and research do not.
